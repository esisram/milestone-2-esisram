# how to run

1. git clone https://github.com/revou-fsse-5/milestone-2-esisram.git
2. npm install
3. npm npm install react-router-dom @types/react-router-dom axios yup @hookform/resolvers react-hook-form
4. npm run build
5. npm run start atau link berikut [Esis Online Store](https://flourishing-mermaid-561d7e.netlify.app/) 👋
